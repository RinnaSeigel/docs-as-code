# Анализатор отзывов

Сервис автоматически определяет тональность текстового отзыва: положительная, нейтральная или отрицательная.  
Пользователь отправляет отзыв, система обрабатывает текст с помощью ML-модели и возвращает результат классификации.

Основные пользователи:
- пользователь (клиент, оставляющий отзыв);
- аналитик (сотрудник, просматривающий статистику тональности).

Основные функции:
- отправка текстового отзыва;
- определение тональности отзыва;
- просмотр результата классификации.

## Комплект документации

1. **Описание проекта** – для всех участников команды и заказчика, чтобы понять назначение и границы системы.
2. **Требования** – для разработчиков и тестировщиков, чтобы знать, какие функции должны быть реализованы.
3. **Архитектура системы** – для разработчиков и DevOps, чтобы понимать компоненты и их взаимодействие.
4. **Документация ML-модели** – для ML-инженеров и аналитиков, чтобы знать, как обучалась модель, её метрики и ограничения.
5. **Документация API** – для фронтенд-разработчиков и внешних интеграций, чтобы правильно вызывать сервис.
6. **Руководство пользователя** – для конечных пользователей, чтобы научиться отправлять отзывы и читать результат.
