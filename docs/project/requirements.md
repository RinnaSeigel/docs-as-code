# Требования

## User Stories

### US-01. Определение тональности отзыва

Как пользователь,  
я хочу отправить текст отзыва и получить его тональность,  
чтобы быстро понять, как отзыв будет воспринят.

**Критерии приёмки:**
- система принимает текстовый отзыв длиной от 1 до 5000 символов;
- после обработки отображается одна из трёх категорий: «положительная», «нейтральная», «отрицательная»;
- если текст пустой или слишком длинный, пользователь получает сообщение об ошибке.

### US-02. Просмотр истории отзывов

Как аналитик,  
я хочу видеть список последних отзывов с их тональностью,  
чтобы отслеживать общую картину настроений клиентов.

**Критерии приёмки:**
- система отображает последние 20 отзывов;
- для каждого отзыва показаны текст (сокращённый) и определённая тональность;
- список можно обновить без перезагрузки страницы.

### US-03. Ручная корректировка результата

Как аналитик,  
я хочу иметь возможность изменить автоматически определённую тональность,  
чтобы исправить ошибку модели и сохранить точные данные.

**Критерии приёмки:**
- рядом с каждым отзывом есть кнопка «Изменить тональность»;
- после изменения система сохраняет новое значение и помечает отзыв как «скорректированный вручную»;
- изменение фиксируется в журнале действий.

## Use Case

### UC-01. Определение тональности отзыва

**Актор:** пользователь

**Цель:** получить тональность отправленного отзыва.

**Предусловие:** пользователь открыл форму отправки отзыва.

**Основной сценарий:**
1. Пользователь вводит текст отзыва и нажимает «Отправить».
2. Система проверяет текст на допустимость.
3. Система передаёт текст ML-модели.
4. ML-модель определяет тональность (положительная / нейтральная / отрицательная).
5. Система получает результат и отображает его пользователю.

**Альтернативный сценарий:**
- Если модель не может обработать текст (например, внутренняя ошибка), система сообщает: «Не удалось определить тональность. Попробуйте позже или обратитесь в поддержку».

**Результат:** пользователь видит определённую тональность отзыва или сообщение об ошибке.
