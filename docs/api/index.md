# API

API предоставляет доступ к функциям ИИ-сервиса **Анализатор отзывов** — 
автоматическое определение тональности текстового отзыва.

## Основные операции

- `POST /analysis` — отправить отзыв на анализ тональности;
- `GET /analysis/{id}` — получить ранее сохранённый результат анализа;
- `GET /models` — получить список доступных версий ML-модели.

## Формат ответа

Каждый успешный ответ анализа содержит:

- `sentiment` — тональность (`positive`, `neutral`, `negative`);
- `confidence` — уверенность модели от `0.0` до `1.0`;
- `modelVersion` — версия использованной ML-модели;
- `id` — идентификатор результата для последующего запроса через `GET /analysis/{id}`.

## Ошибки

API возвращает структурированные ошибки в формате:

```json
{
  "code": "INVALID_TEXT",
  "message": "Text must not be empty"
}
